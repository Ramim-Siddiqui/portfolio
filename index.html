01

Voice AI Patient Registration Agent

A phone agent that registers patients through natural conversation.

Overview

Callers dial a real U.S. number and talk to Riley, an intake coordinator built on Vapi. Riley collects the standard patient demographics in any order, spells names back, rejects impossible answers such as a birth date in the future, reads everything back for confirmation and only then writes the record. Returning callers are recognised by phone number and must confirm their date of birth before anything is changed.

Highlights

  • Tool-calling agent with five backend tools: patient lookup, registration, update, appointment slots and booking.
  • One validation layer shared by the voice tools and the REST API, so the phone channel can never store what the API would reject.
  • Honest failure handling: when a write fails the agent says so and offers a retry; it never claims success.
  • Transcript, summary and cost stored for every call and shown on a live dashboard.

02

Support Ticket Resolution Agent

An agentic workflow that drafts support replies and checks its own work.

Overview

A LangGraph state machine classifies each ticket, retrieves the matching knowledge-base passages with Gemini embeddings, drafts a reply with Gemini and reviews the draft against explicit rules: greet the customer, ground every fact in the retrieved context, never promise a refund. A failed draft is refined and retried; after two rejections the ticket goes to a human with the full trace logged.

03

Detecting Source-Code Vulnerabilities with Graph Neural Networks

Final-year research: graph classification over the syntax trees of C and C++ functions.

Overview

Each function in the Devign dataset, 27,318 functions from FFmpeg and QEMU, is parsed with libclang into an abstract syntax tree, linearised into node-kind and identifier tokens, and encoded as a PyTorch Geometric graph over a 54,823-entry vocabulary. A three-layer GraphSAGE network with global mean pooling then labels the function as vulnerable or not.

04

Smart Form Filler

Record one data-entry session, then replay it for every row of a spreadsheet.

Overview

Built for web portals that have no import feature and no API. The user signs in by hand, records a single entry and maps each typed value to an Excel column; the tool then drives a real Chrome window through every remaining row, verifies each submission and writes a status for every row. Interrupted runs resume where they stopped.

Highlights

  • A recorder injected into the page captures clicks, typed values, dropdowns and dates with stable selectors. Password fields are detected and never stored.
  • Automatic column matching, date reformatting and a per-row success check.
  • Up to nine copies run side by side, each with its own browser profile, login and ports.
Design
Browser controlPlaywright over the Chrome DevTools Protocol
InterfaceStreamlit, six guided steps

Built with Python · Playwright · Streamlit · pandas

05

GitHub Stars Crawler

Collecting star counts for up to 100,000 repositories in a CI pipeline.

Overview

A Python crawler that runs inside GitHub Actions next to a PostgreSQL service container. It queries the GitHub GraphQL API in date slices to get past the 1,000-result search cap, upserts every repository's star count, records its progress so a run can resume, and exports a CSV and a database dump as build artifacts.

Highlights

  • Date-sliced GraphQL search with cursor pagination.
  • Rate-limit aware: waits for the quota to reset and retries server errors with exponential backoff.
  • Idempotent upserts and a state table, so interrupted runs resume where they stopped.

Built with Python · GraphQL · PostgreSQL · GitHub Actions

Source code and workflow
